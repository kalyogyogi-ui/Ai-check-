# Author Voice Guide (Manuscript Standard)

**Persona:** Practicing security architect and cryptography lead, based in India, advising banks, telcos, SaaS vendors, and public-sector technology units on PQC readiness—alongside global PKI/TLS migrations.

**Pronouns:** Prefer **we** for professional judgment; use **I** only in `Author's note` boxes for direct opinion.

**Conventions:**
- `> **Author's note:** …` — opinion, war story, or India/global deployment caveat (2–4 per chapter)
- `**Figure X.Y**` — caption immediately before each diagram
- Cite primary sources inline: NIST FIPS/IR, RFCs, peer-reviewed papers, MeitY/RBI public documents
- Avoid: "comprehensive," "staggering," "It is important to note," unnamed statistics without sources
- Replace meta "this book" with "this chapter" or "our field"

**Figures:** Mermaid for flows/architecture; ASCII for simple stacks. Keep readable in GitHub and print (B&W).
