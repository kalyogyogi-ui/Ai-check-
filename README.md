# Prompt Resources 38shift 🚀

Welcome to the **Prompt Resources 38shift** repository. This is a curated collection of high-quality, structured prompts designed to unlock the full potential of Large Language Models across various domains.

38shift.com is an AI-first engineering and technology consultancy, where human expertise and machine intelligence work together to create category defining digital experiences.

## 📂 Repository Structure

The prompts are organized into specific categories within the `categories/` directory. Each category contains specialized prompts tailored for specific tasks and workflows.

### 🏛️ Categories

1. **[Nano Banana Images](categories/nano-banana-images/README.md)**: Specialized prompts for generating and manipulating "Nano Banana" themed imagery.
2. **[Software Development](categories/software-development/README.md)**: Prompts for coding, debugging, architecture design, and technical documentation.
3. **[Content Creation](categories/content-creation/README.md)**: Writing, copywriting, scriptwriting, and creative storytelling prompts.
4. **[System Instructions](categories/system-instructions/README.md)**: High-level system prompts for defining AI personas and behavioral constraints.
5. **[Business Analysis](categories/business-analysis/README.md)**: Market research, data interpretation, financial modeling, and strategy development.

## 🛠️ How to Use

Simply navigate to the category of interest and browse the available markdown files. Each file contains:

- **Objective**: What the prompt aims to achieve.
- **The Prompt**: The actual text to be used.
- **Parameters**: Recommended settings (temp, top-p, etc.) if applicable.
- **Example Output**: A sample of what to expect.
