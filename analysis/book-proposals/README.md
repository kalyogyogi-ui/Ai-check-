### Generation prompts

Master prompts for producing the full manuscript of a proposed book chapter-by-chapter. Each is engineered for a frontier LLM, enforces a single author voice across 24 chapters, mandates 8,000–9,000 words per chapter with embedded visuals (Mermaid diagrams, ASCII layouts, tables, original code listings, callouts), and applies hard rules against marketing register, AI-hype phrasing, copyrighted material, and LLM-default tics.
